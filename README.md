🚀 Dashboard Portfolio
A premium, dark-themed dashboard-style portfolio perfect for OLJ (OnlineJobs.ph) freelancers.
📁 Files
index.html - Main portfolio page
style.css - All styling (dark theme, grid layout, animations)
script.js - Interactivity and hover effects
🛠️ How to Customize
1. Replace "YOUR NAME"
Open index.html and find:
HTML
<div class="highlight-name">[YOUR NAME]</div>
Replace with your actual name.
2. Update Email & Social Links
Find the contact section and update:
HTML
<a href="mailto:your.email@example.com" title="Email">
3. Add Your Real Projects
Replace the placeholder project thumbnails with actual screenshots:
HTML
<div class="thumb-img">
    <img src="your-project-screenshot.png" alt="Project Name">
</div>
4. Update Tech Stack
Add/remove tech items in the .tech-grid section.
5. Update Service Packages
Modify the .services-grid to match your actual services.
🚀 Deploy to GitHub Pages
Step 1: Create GitHub Repo
Go to github.com
Click New Repository
Name it: yourusername.github.io
Make it Public
Click Create
Step 2: Upload Files
Click "uploading an existing file"
Drag & drop: index.html, style.css, script.js
Click Commit changes
Step 3: Visit Your Site
Go to: https://yourusername.github.io
Done! 🎉
